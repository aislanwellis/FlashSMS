Como configurar

Facilita Móvel: cadastre em facilitamovel.com.br. Pegue usuário e senha no painel. Preencha FACILITA_USER e FACILITA_PASS. Modo json ou http.

SMSFire: cadastre em smsfire.com.br. Gere o token em Configurações → API Token. Cole em SMSFIRE_TOKEN.

LigueLead: acesse areadocliente.liguelead.app.br. Vá em Integrações → API Token. Crie um App e copie o API Token e o App ID. Cole em LIGUELEAD_API_TOKEN e LIGUELEAD_APP_ID.
